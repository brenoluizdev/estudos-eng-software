2. Estrutura de um programa C

#include <stdio.h>      // biblioteca: printf e scanf
int main(){              // função principal: o programa começa aqui
    float n1, n2, media; // declaração: <tipo> <nome>;
    scanf("%f", &n1);    // entrada: & = endereço da variável
    scanf("%f", &n2);
    media = (n1 + n2) / 2;  // processamento
    printf("Media = %.2f\n", media);  // saída com 2 casas
    return 0;            // 0 = terminou sem erro
}
TipoBytes (típico)Observação

int / short int / unsigned int4 / 2 / 4int: −2.147.483.648 a 2.147.483.647 · unsigned: só não negativos

bool—exige #include <stdbool.h>
Constantes: #define PI 3.14 (sem ;, sem tipo, não ocupa memória, não aceita &) × const float g = 9.8; (tem tipo, ocupa memória, alterar dá erro de compilação).
Nomes de variáveis: começam com letra; só letras, números e _; sem espaço, acento ou outro símbolo. C diferencia maiúsculas: valor ≠ Valor. O próprio material tinha float salário (inválido) — veja a nota de revisão da U2 · Aula 1.

EstruturaRegra que cai na prova

break no switchsem ele, a execução “cai” nos case seguintes
switch (op) {          // op = 2
    case 1: printf("A");
    case 2: printf("B");   // entra aqui...
    case 3: printf("C");   // ...cai aqui (sem break)

    default: printf("?");
}

1. Variáveis compostas

EstruturaTipoDeclaraçãoAcesso
Vetorhomogênea, 1 dimensãoint v[5];v[0] … v[4]
Stringvetor de char terminado em '\0'char nome[16]; (15 úteis)%s
Matrizhomogênea, 2+ dimensõesfloat t[5][2];t[linha][coluna]

Vetor é estático: o tamanho é fixado na declaração e não muda. Sem inicializar, as posições contêm lixo. Diagonal principal: m[i][i]; secundária (3×3): m[i][2 - i].
Strings: scanf("%s", nome) (sem &) para no primeiro espaço; fgets(frase, 101, stdin) lê a frase inteira e pode guardar o '\n'. Não se faz nome = "Ana"; depois da declaração: use strcpy(nome, "Ana"). Comparar: strcmp(a, b) == 0.
typedef struct {          // typedef: dispensa a palavra struct na declaração
    char titulo[100];
    int estoque;
} Livro;                  // struct criada antes do main()

Livro livros[3];                 // vetor de structs
livros[1].estoque = 5;           // índice primeiro, depois .campo

2. Ponteiros

int ano = 2018;
int *p = &ano;   // p guarda o ENDEREÇO de ano
*p = 2024;        // altera ano através de p (desreferência)
printf("%p", p);  // endereço  ·  printf("%d", *p) → 2024
ExpressãoSignificado
&xendereço de x (operador de referência)
*pconteúdo apontado por p
p++ / p + kavança 1 / k elementos (soma k · sizeof(*p) bytes)
(*p)++incrementa o valor apontado
p = v;o nome do vetor já é o endereço de v[0]
ptr->campoo mesmo que (*ptr).campo
NULL“não aponta para nada”
Pegadinhas: ponteiros só aceitam soma e subtração de inteiros. </> entre ponteiros só fazem sentido dentro do mesmo vetor. Matriz fica na memória linha por linha: m[i][j] está na posição i · colunas + j.

🧮 Ferramenta: onde fica cada elemento na memória

Com 1 linha, é um vetor v[colunas] e o elemento é v[j]. Com mais linhas, é uma matriz m[linhas][colunas]. Endereços fictícios, em decimal.

4. Recursividade

int fatorial(int n) {
    if (n > 0)
        return n * fatorial(n - 1);  // chamada recursiva
    else
        return 1;                    // caso base: 0! = 1
}
Sem caso base (ou com um caso base que nunca é alcançado, como somar(-3) com if (valor != 0)) as instâncias se acumulam até o estouro de pilha. Toda recursão tem versão iterativa; a recursiva costuma usar mais memória.
