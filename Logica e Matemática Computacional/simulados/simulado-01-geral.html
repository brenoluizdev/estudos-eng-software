Combinatória

  • A ordem importa? Não → C(n,k) = n!/(k!(n−k)!)
  • Sim, sem repetir → A(n,k) = n!/(n−k)!
  • Sim, pode repetir → nᵏ
  • Usa todos (anagrama) → P(n) = n!
  • C(n,k) = A(n,k) ÷ k!

Conjuntos

  • ∪ em pelo menos um · ∩ nos dois
  • A − B: em A e não em B
  • A Δ B: em exatamente um
  • |A ∪ B| = |A| + |B| − |A ∩ B|
  • nº de subconjuntos = 2ⁿ · |A×B| = |A|·|B|

Lógica

  • P → Q só é F quando V → F
  • P ↔ Q é V quando os valores são iguais
  • P → Q ≡ ¬Q → ¬P ≡ ¬P ∨ Q
  • ¬(P ∧ Q) ≡ ¬P ∨ ¬Q · ¬(P ∨ Q) ≡ ¬P ∧ ¬Q
  • ✅ MP, MT, SH · ❌ afirmar consequente, negar antecedente

Tabela verdade

  • n proposições → 2ⁿ linhas
  • AND: V só se todas V · OR: F só se todas F
  • Tautologia = tudo V · Contradição = tudo F
  • Contingência = misto
  • Precedência: ( ) → ¬ → ∧/∨ → → → ↔

1. O vocabulário da lógica (cai em asserções e V/F)

TermoDefinição que a prova usa
ProposiçãoFrase declarativa que pode ser valorada como V ou F, nunca as duas. Pergunta, ordem e exclamação não são proposições. Uma proposição falsa continua sendo proposição.
PremissaProposição usada como base de um raciocínio (as "hipóteses").

InferênciaProcesso de chegar a conclusões a partir de premissas. Pode ser dedutiva ou indutiva.
FaláciaArgumento logicamente incorreto (inferência inválida).
DeduçãoIndução
Direçãogeral → particularparticular → geral
Conclusãonecessária (se as premissas são V)provável (cai com um contraexemplo)
ExemploTodo dev sabe lógica; Ana é dev ⇒ Ana sabe lógicaO sol nasceu todos os dias ⇒ nascerá amanhã
Validade ≠ verdade. "Todo gato voa; Mimi é gato; logo Mimi voa" é um argumento válido (a forma está correta) com premissa falsa. A lógica avalia a forma.

Também aparece em provas antigas: a lógica clássica tem 3 princípios: identidade (P é P), não contradição (não pode ser V e F ao mesmo tempo) e terceiro excluído (ou é V ou é F). Os períodos da lógica são Aristotélico, Booleano e Atual. Na álgebra booleana, + é o "ou" e × é o "e", com 1 = V e 0 = F.

2. Silogismos com "todo / algum / nenhum" (muito cobrado nas provas antigas)

Desenhe as afirmações como conjuntos (diagrama de Venn) e só aceite a conclusão que vale em todos os desenhos possíveis.

AfirmaçãoDesenho
Todo A é Bcírculo A dentro de B (A ⊆ B)
Algum A é BA e B têm interseção não vazia
Nenhum A é BA e B separados (A ∩ B = ∅)

Exemplo de prova: "Alguns homens altos são bonitos e todos os homens altos são inteligentes." Os altos-bonitos estão dentro de "inteligentes", então algum homem bonito é inteligente. "Todo inteligente é alto" não decorre, porque "todo A é B" não permite inverter.

3. Análise combinatória: escolher a fórmula certa

A ordem importa?  (trocar a ordem gera outro resultado?)
├── NÃO → Combinação         C(n,k) = n! / (k!·(n−k)!)
└── SIM → Pode repetir elemento?
          ├── SIM → Arranjo c/ repetição  nᵏ
          └── NÃO → Arranjo simples       A(n,k) = n! / (n−k)!
                    └── usa todos (k = n) → Permutação P(n) = n!
SituaçãoOrdem importa?Conta
Pódio (1º, 2º, 3º) entre 8Sim: ouro ≠ prataA(8,3) = 8·7·6 = 336
Comissão de 3 entre 8Não: {Ana, Bia, Caio} é o mesmo grupo em qualquer ordemC(8,3) = 336 ÷ 3! = 56
Senha de 4 dígitos, pode repetirSim + repete10⁴ = 10.000
Anagramas de BRASILSim, usa todas6! = 720
Armadilhas clássicas: (1) As alternativas costumam trazer o valor do arranjo e o da combinação lado a lado. Antes da conta, escreva "ordem importa? S/N". (2) Dígitos de 0 a 9 são 10 opções: o zero conta. (3) "Tem cargo, posição ou sequência?" Então é arranjo. "É só um grupo, time ou pote?" Então é combinação.
Atalho de conta: A(n,k) é o produto dos k primeiros fatores: A(10,3) = 10·9·8. Para a combinação, divida por k!: C(10,3) = 720 ÷ 6 = 120. Nunca precisa calcular 10! inteiro.

1. Proposições simples e compostas

Uma proposição composta junta duas ou mais proposições simples com conectivos.

ConectivoSímboloLê-seEm códigoSó é F quando… / só é V quando…
Negação¬ (ou ~)não!pinverte o valor
Conjunção∧e, mas, no entantop && qV só se as duas forem V

Bicondicional↔se e somente sep === qV quando os dois são iguais
"Ou" inclusivo × exclusivo (caiu em AV2; o material das aulas só define o inclusivo): o inclusivo permite as duas coisas ao mesmo tempo ("Rodrigo é estudante ou trabalhador": pode ser os dois). O exclusivo é quando as duas não podem acontecer juntas ("Maria é paulista ou carioca", "Arthur é baixo ou alto"). Em código: p !== q (XOR).

Tradução (cai sempre): p = "Fortaleza é linda", q = "Curitiba é fria". "Fortaleza é linda e Curitiba não é fria" = p ∧ ¬q. Repare que a negação fica só no q.

Variações de P → Q: a contrapositiva ¬Q → ¬P é equivalente (mesma tabela). A recíproca Q → P e a inversa ¬P → ¬Q não são. A negação de P → Q é P ∧ ¬Q.
Exemplo de prova: "Se eu estivesse atento, teria solucionado o crime" ≡ "Se eu não solucionei o crime, então não estava atento".
Atenção: P é sempre o que vem depois do "se" e Q o que vem depois do "então", seja qual for a ordem das frases no enunciado. O gabarito da plataforma (exercício U3 · Q1) aceitou "se não tem penas, não é ave" como válido, mas isso é negar o antecedente, uma falácia.

3. fbf e precedência

Uma fórmula bem-formulada (fbf) segue a sintaxe: sempre há um conectivo entre duas proposições. O ¬ pode vir junto de outro conectivo. Exemplos: (A → B) ∨ C é fbf. A ∧ ∨ B e A B → não são.

Ordem de avaliação (Unidade 3, Aula 2): ( ) mais internos → ¬ → ∧ e ∨ (mesmo nível, da esquerda para a direita) → → → ↔. Assim, A → B ∧ ¬C é lido como A → (B ∧ (¬C)).

2. Classificação

TipoÚltima colunaExemplo
Tautologiatudo VP ∨ ¬P · (P → Q) ↔ (¬Q → ¬P)
Contradiçãotudo FP ∧ ¬P
ContingênciaV e F misturadosP → Q · (P ∨ Q) ∧ (¬Q ∨ R)
Equivalência: duas fórmulas são equivalentes quando têm a mesma coluna final em todas as linhas (ou quando o ↔ entre elas é tautologia). Para provar que não são, basta uma linha diferente.
Atalhos de prova: num AND, procure um F (ele derruba tudo). Num OR, procure um V (ele garante tudo). Numa →, só calcule se o antecedente for V.
Pegadinhas: "p → q tem a mesma tabela que q → p" é falso. "Tabela verdade só serve para proposições simples" é falso. Em ¬A ∧ B, o ¬ atinge só o A. Em ¬(A ∧ B), atinge tudo.

Aplicação (Aula 4): todo if com and/or/not é uma fbf. Filtros de busca ("apartamento E (1 OU 2 quartos)") e regras de negócio ("se não for Brasília e for gasolina, então a bandeira é Petrobras" = (¬A ∧ B) → C) são avaliados linha a linha.
