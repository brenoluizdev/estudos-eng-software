## Questão 1 ⬜

O operador lógico "AND" (ou "E" em português) em lógica e matemática computacional é usado para combinar duas ou mais proposições, resultando em verdadeiro (1) somente se todas as proposições forem verdadeiras. Se pelo menos uma das proposições for falsa, o resultado é falso (0). O operador "AND" é fundamental para criar condições de conjunção e é amplamente utilizado em programação para estabelecer critérios que todas as condições devem atender para que uma ação seja executada.

Suponha que você está verificando se pode assistir a um filme no cinema (C) e tem duas condições:

- Você assistirá ao filme se a classificação etária permitir (**Classificação**).
- Você também assistirá ao filme se seus amigos quiserem ir (**Amigos**).

Você pode representar sua decisão usando a seguinte proposição:

> **Classificação AND Amigos**

**Pergunta:** Construa a tabela verdade correspondente e determine se você assistirá ao filme no cinema ou não para todas as combinações possíveis de Classificação e Amigos.

**Alternativas:**

- A) Você assistirá ao filme no cinema apenas se a classificação etária permitir, independentemente de seus amigos quererem ir.
- B) Você assistirá ao filme no cinema apenas se seus amigos quiserem ir, independentemente da classificação etária permitir.
- C) Você assistirá ao filme no cinema apenas se a classificação etária não permitir e seus amigos não quiserem ir.
- D) Você não assistirá ao filme no cinema a menos que a classificação etária permitir e seus amigos queiram ir.
- E) Você assistirá ao filme no cinema se a classificação etária permitir e seus amigos quiserem ir.

## Questão 2 ⬜

Ela é usada para determinar o valor de verdade de uma expressão lógica, onde "AND" retorna verdadeiro apenas se ambas as condições são verdadeiras, "OR" retorna verdadeiro se pelo menos uma das condições é verdadeira, e "NOT" inverte o valor de verdade da condição de entrada.

Considere a seguinte expressão lógica:

> **(NOT A) AND (B OR (NOT C))**

**Pergunta:** Qual das seguintes combinações de valores de A, B e C resulta em um valor verdadeiro (True) para a expressão lógica?

**Alternativas:**

- A) A = True, B = False, C = False
- B) A = False, B = False, C = True
- C) A = True, B = True, C = True
- D) A = False, B = True, C = True
- E) A = True, B = False, C = True

| 5 | True | False | False | False |

- A) False, False, True, True, False.
- B) True, False, True, True, False.
- C) False, True, True, True, False.
- D) True, True, True, False, False.
- E) True, False, True, False, True.
