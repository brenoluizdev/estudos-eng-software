## Tópicos abordados
- Modelo Cascata: identificação da fase de "Projeto" a partir de uma descrição

- CMM (Capability Maturity Model): identificar o nível de maturidade a partir de um cenário
- Metodologias ágeis: prática de "histórias do cliente" para levantamento de requisitos
- Papéis em metodologias ágeis (analista de testes, desenvolvedor, Scrum Master) — V/F
