# Prova Presencial 1ª Chamada — Engenharia de Software (Unopar)

## Tópicos abordados
- Manutenção de software: classificação (adaptativa, corretiva, evolutiva)
- Ciclo de vida da auditoria de sistemas (planejamento, execução, relatório)
- Casos de teste: definição e características
- Desenvolvimento Orientado a Testes (TDD) — ordem correta do processo
- ISO 9126: partes da norma e o que cada uma avalia
- Métricas de qualidade de software (requisitos, preparação, avaliação)
- Vantagens de adotar uma metodologia definida no processo de desenvolvimento
- Metodologias ágeis e o papel do cliente/feedback
- Auditoria terceirizada (inspeção, contínua, de controle)
- Requisitos Funcionais (RF) vs. Não Funcionais (NF) — como distinguir
- Objetivo do TDD (identificar/corrigir falhas durante o desenvolvimento)
- Técnicas de teste (caixa preta/caixa branca) x tipo de erro detectado
