# Prova de Engenharia de Software — Estudo e Revisão

## Tópicos abordados
- Metodologias ágeis: XP, Scrum e FDD (o que têm em comum)
- Auditoria de controles organizacionais e operacionais
- Fases do modelo Cascata (requisitos, projeto, implementação, teste, manutenção)
- Causas de erro/falha em software (baseado em PINHEIRO, 2015)
- As 4 grandes etapas do processo de teste de software
- Técnica de teste (caixa preta/branca) x tipo de erro detectado
- Extreme Programming (XP): conceito de "código coletivo"
- Auditoria de sistemas aplicativos
- Elementos do Scrum (Product Backlog, Sprint Backlog, Sprint)
- Medidas, métricas e indicadores de software — V/F
- Modelos de processo de gestão de projetos (Scrum)
- Gestão de configuração de software
- Teste de unidade
- Test-Driven Development (TDD): prática e conceitos correlatos
