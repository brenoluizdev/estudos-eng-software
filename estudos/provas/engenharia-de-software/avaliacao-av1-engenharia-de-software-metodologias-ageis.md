# AV1 — Engenharia de Software (Anhanguera, 2022)

## Tópicos abordados
- Manifesto Ágil: princípios (participação do cliente, ritmo de entregas, adaptação a mudanças)
- Extreme Programming (XP): asserção sobre inclusão do cliente no time de desenvolvimento
- CVS (Concurrent Versions System): operações básicas (checkout, commit, update, import)
- Versionamento no CVS: quando uma nova revisão é gerada
- Conceito de "release" no ciclo de vida do software

## Observação
Única prova do lote que aborda controle de versão (CVS) com esse nível de
detalhe — vale revisar junto com o conteúdo de gerência de configuração de
software.
